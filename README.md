# ぽん通知 LP

「ぽん通知」は仮称です。正式名称は未定で、サブ候補として「わん通知」も検討しています。

## 目的

動物たちのかわいい合図を、Apple Watchやスマートウォッチ、スマホのロック画面ウィジェットから“ワン”タップで送る体験に需要があるかを検証するLPです。現時点では本アプリではなく、SNS流入、コンセプト検証、開発通知登録を目的にしています。

## アプリ概要

親しい相手に、肉球ボタンから「帰るよ」「大丈夫？」「見て」「思い出した」などの合図を送る構想です。受信側にはバイブのあと、その人が登録した動物が走ってきて、ジェスチャーで合図を届けます。短いメッセージは主役ではなく、ジェスチャーの意味を補助するラベルとして扱います。

Apple Watch / スマートウォッチ / iPhoneロック画面ウィジェットは将来対応予定です。初期MVPでは犬のみ、かつ一部送信方法だけになる可能性があります。

## 現在の検証仮説

- 動物のかわいい合図をワンタップで届ける体験に需要がある
- Apple Watch / スマートウォッチやロック画面から送れることに魅力がある
- 立体的な肉球ボタンを押して送る体験が直感的に伝わる
- 犬が走ってきてジェスチャーで合図を届ける演出が好まれる
- メッセージよりジェスチャー中心の通知体験に魅力がある
- 事前登録・開発通知登録につながる

## Vercel公開手順

公開URL: https://pon-notify-lp.vercel.app/

1. GitHubに `pon-notify-lp` リポジトリを作成します。
2. このリポジトリをGitHubへpushします。
3. Vercelで「Add New Project」からGitHubリポジトリを選択します。
4. Framework Preset が Next.js になっていることを確認します。
5. Build Command は `npm run build`、Install Command は `npm install` のままで公開できます。
6. 独自ドメインやOGP画像は公開後に差し替えます。

## フォーム差し替え方法

フォームURLは `src/constants/site.ts` にまとめています。

```ts
export const FALLBACK_FORM_URL = "https://tally.so/r/replace-pon-notify";
```

Googleフォーム、Tally、Formspreeなどの本番URLに差し替えてください。Vercel環境変数で差し替える場合は `NEXT_PUBLIC_FORM_URL` にフォームURLを設定すると、コードを触らずにリンク先を変更できます。

現在のフォームは仮実装です。静的LPとして扱いやすくするため、ログイン、ユーザー管理、Push通知、送信APIは実装していません。
