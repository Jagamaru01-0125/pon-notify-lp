# ぽん通知 LP

「ぽん通知」は仮称です。正式名称は未定で、サブ候補として「わん通知」も検討しています。

## 目的

動物たちのかわいい合図を、Apple Watchやスマートウォッチ、スマホのロック画面ウィジェットから“ワン”タップで送る体験に需要があるかを検証するLPです。現時点では本アプリではなく、SNS流入、コンセプト検証、開発通知登録を目的にしています。

## アプリ概要

親しい相手に、肉球ボタンから「帰るよ」「大丈夫？」「見て」「すき」などの合図を送る構想です。受信側にはバイブのあと、その人が登録した動物が走ってきて、ジェスチャーで合図を届けます。短いメッセージは主役ではなく、ジェスチャーの意味を補助するラベルとして扱います。

Apple Watch / スマートウォッチ / iPhoneロック画面ウィジェットは将来対応予定です。初期MVPでは犬のみ、かつ一部送信方法だけになる可能性があります。

## 現在の検証仮説

- 動物のかわいい合図をワンタップで届ける体験に需要がある
- Apple Watch / スマートウォッチやロック画面から送れることに魅力がある
- 立体的な肉球ボタンを押して送る体験が直感的に伝わる
- 犬が走ってきてジェスチャーで合図を届ける演出が好まれる
- メッセージよりジェスチャー中心の通知体験に魅力がある
- 事前登録・開発通知登録につながる

## リポジトリ構成

現在のLPは **`lp-v2/`** にある静的HTML版です(claude.ai/design の pom-LP2 ハンドオフから実装)。
旧Next.js版LPは削除済みです(履歴には残っています)。

```
lp-v2/
  index.html   … LP本体(ビルド不要・単体で動作)
  web/         … CSS / JS / 画像アセット
```

## LP構成(lp-v2)

1. ファーストビュー
2. 共感(文章では伝えづらい瞬間)
3. 使い方3ステップ
4. 4画面モック(ホーム / ロック画面 / 受信 / 設定)
5. 合図パターン(インタラクティブ切り替え)
6. 届く体験
7. なでる(既読のかわり)
8. ロック画面ウィジェット & Apple Watch
9. お届け履歴
10. 安心設計
11. 事前登録フォーム

## ローカルで見る方法

ビルドは不要です。`lp-v2/index.html` をブラウザで直接開くか、簡易サーバーで確認できます。

```bash
python -m http.server 8765
# → http://localhost:8765/lp-v2/
```

## 公開について

静的ファイルのみなので、GitHub Pages / Vercel / Netlify などにそのまま置けます。
Vercelの場合は Framework Preset を「Other」にし、`lp-v2` を公開ディレクトリとして指定してください。
